Sources, coverage and gaps

This tool follows the four country-based visitor, super visa, study and work permit series in the IRCC country feed. Country coverage varies by observation. The official form may show other estimates or individual considerations for your situation.

Processing times are published estimates. A backward-looking measure describes how long previous applications took. A forward-looking estimate uses current conditions. Service standards are separate commitments. For the applicable measure and current advice, use IRCC’s explanation.

The table links each point to the source checked directly, a timestamped Wayback capture, or a preserved copy of the official file in an independent GitHub archive. The CSV includes a SHA-256 hash of each source. Recorded changes can reflect new estimates or corrections. Missing dates stay unfilled. Selections run in the browser.
